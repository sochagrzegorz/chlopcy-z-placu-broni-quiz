# Sprawdzian: „Chłopcy z Placu Broni”

Prosta aplikacja webowa w jednym pliku HTML. Działa na telefonach i komputerach, również bez połączenia z internetem.

## Uruchomienie

1. Pobierz albo skopiuj plik `index.html` na telefon lub komputer.
2. Otwórz go w przeglądarce (np. Chrome, Safari, Firefox lub Edge).
3. Uczeń wypełnia quiz i wybiera **Sprawdź wynik**. Wynik obejmuje pytania zamknięte; odpowiedzi opisowe ocenia nauczyciel.

Nie trzeba instalować dodatkowych programów ani uruchamiać serwera.

## Publikacja jako strona

Umieść `index.html` na dowolnym statycznym hostingu, np. GitHub Pages, Netlify lub na własnym serwerze WWW. Można też zmienić nazwę pliku na `index.html` w katalogu głównym witryny. Hosting nie jest potrzebny do lokalnego używania quizu.

## Funkcje

- pięć sekcji: wybór odpowiedzi, prawda/fałsz, dopasowywanie, krótkie odpowiedzi i dłuższa wypowiedź;
- automatyczne punktowanie 13 pytań zamkniętych;
- wersja uczniowska bez klucza odpowiedzi;
- drukowanie lub zapis do PDF z poziomu przeglądarki;
- układ dopasowany do małego ekranu;
- odpowiedzi pozostają w przeglądarce i nie są wysyłane na serwer.

Treść quizu przygotowano na podstawie lektury, ponieważ w podglądzie wcześniejszej rozmowy nie była dostępna treść pierwotnego sprawdzianu.
